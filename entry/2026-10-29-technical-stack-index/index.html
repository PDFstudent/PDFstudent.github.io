覆盖范围

历史采集台账记录了 47 个会话、792 个可用回合和 786 条用户提问；另有 2 个 ChatGPT 来源只有摘要预览。这些数字表示采集范围，不代表每条技术结论都已逐项验证，也不能证明账号上未连接设备的全部历史均已获取。仅有摘要的来源无法按完整对话复核。

分类单位是对话回合，不是 Chat 窗口。同一 Chat 中关于模型、训练、部署或安全控制的不同回合会分别进入对应专题；同一回合如果同时涉及定位、导航与工程部署，也允许挂接多个专题。

公开页面只保留长期可复用的知识。设备信息、访问凭据、内部链接、本地路径、私人仓库配置、完整日志和原始聊天均不公开。

分类原则

分类不按 Chat 窗口、项目名称或最初举例固定，而按知识问题的输入、输出和验证方法划分。路线规划回答“走哪里”，运动控制回答“怎样执行”，安全层回答“什么动作不能执行”；具身模型回答“怎样从数据预测意图或轨迹”，人形控制回答“怎样在接触动力学约束下实现运动”。

同一历史回合仍可为多个专业提供证据，但公开文章只保留一个主要归属，并通过专题导航和正文交叉链接表达依赖关系。

六条技术主线

1. SLAM 与多传感器定位

覆盖激光与点云处理、Fast-LIO、关键帧地图、增量建图、动态残影、全局重定位、反光地标、视觉标志姿态、坐标变换和远程诊断。

适合回答的问题是：机器人如何建立地图、估计自身状态、发现定位失效，并用不同传感器互相校验。

专题目录：SLAM 技术。

2. 路线规划与导航系统

覆盖全局规划、指定路线、路线资产、地图注册、一次规划、接入策略、任务生命周期和配置分层。

适合回答的问题是：有了地图与位姿后，业务路线如何成为可执行路径，任务如何开始、暂停、恢复和结束。

专题目录：路线规划与导航系统。

3. 运动控制、精导航与安全

覆盖 RPP、MPPI、Rotation Shim、全向运动、代价地图、footprint 扫掠、障碍等待、视觉精导航和横向微移。

适合回答的问题是：给定路径后，机器人如何生成速度、完成厘米级末端动作，并在任何阶段满足碰撞约束。

专题目录：运动控制、精导航与安全。

4. 具身模型、VLN 与数据闭环

覆盖 Transformer 动作查询、OmTrackVLA、InternVLA-N1、NavDP、DualVLN、时序视觉表示、推理资源和 DAgger 数据闭环。

适合回答的问题是：具体开源模型如何把图像、语言和历史状态转换为导航轨迹，能否在目标硬件运行，以及如何继续训练和安全部署。

专题目录：具身模型、VLN 与数据闭环。

5. 人形机器人动力学与全身控制

覆盖浮动基座动力学、接触力、摩擦锥、MPC 预测规划、WBC 全身优化、任务优先级和执行器接口。

适合回答的问题是：导航或学习模型给出的运动意图，如何在多接触、欠驱动和硬件约束下变成可执行关节动作。

专题目录：人形机器人动力学与全身控制。

6. 机器人工程交付与诊断

覆盖代码工作区关系、交叉编译、完整集成部署、CI 分支判断、磁盘空间、日志权限、文件传输、版本回滚、Linux 软件包锁、桌面环境和实体标签制作。

适合回答的问题是：如何把算法变成可重复构建、可安全部署、可诊断、可验证和可回滚的工程系统。

专题目录：机器人工程交付与诊断。

技术栈之间的依赖关系

SLAM 提供地图、位姿和环境几何；路线规划把业务目标变成路径；运动控制把路径变成受安全约束的速度；具身模型从图像、语言和历史预测意图或局部轨迹；人形控制把意图转成满足接触动力学的全身动作；工程实践保证整套系统可构建、部署、诊断和回滚。

知识库系统不再作为技术专业与算法并列，而是所有专业共同使用的沉淀机制：每日增量记录变化，长期专题吸收稳定知识，覆盖台账追踪原始讨论是否被遗漏。

历史会话覆盖映射

SLAM 技术来源

  • 高反光材料导致异常点云及其同步诊断数据。
  • 平面视觉标志航向漂移和姿态双解。
  • 定位失败、地图位姿、里程计与坐标变换接口。
  • 远程 RViz 与导航调试桥。
  • Fast-LIO 运行负载与进程树分析。
  • PC 端视觉标志检测与质量可视化。
  • 增量建图、关键帧累加和动态残影。
  • 反光地标辅助定位与几何配准。
  • 激光强度字段可视化。
  • 视觉停靠状态日志与重对齐行为。

导航算法来源

  • 指定路线编辑、下发和一次规划。
  • 全向底盘、Rotation Shim、MPPI 与 RPP。
  • 障碍停车等待、静态地图校验和运动扫掠。
  • 后半平面点云过滤及其安全边界。
  • 视觉精导航、六自由度观测和速度控制。
  • 横向微移服务、停车锚点与离站。
  • 仿真与实车配置、任务类型配置和速度链路。
  • 生命周期暂停、定位抖动和任务恢复竞态。
  • 真机启动、路线标注、系统接口和状态报告。

模型基础与 VLN 来源

  • Transformer 为什么需要输出查询位置，以及查询向量训练后的含义。
  • 人形机器人 MPC 与 WBC 的职责、频率和接口。
  • OmTrackVLA 网络结构、动作输出和本机推理可行性。
  • InternVLA-N1 双系统、NavDP、DualVLN 与 RGB、RGB-D 取舍。
  • DAgger 训练阶段、连续轨迹标注、专家接管和危险样本处理。

工程实践来源

  • 地图与构建产物传输、文件完整性校验。
  • 多项目依赖、接口包升级和完整集成部署。
  • CI 失败对应的分支与提交关系。
  • 部署空间峰值、旧备份和回滚策略。
  • 日志目录权限与最小只读授权。
  • 远程桌面、输入法和软件包管理锁。
  • 实体视觉标签尺寸、静区、安装结构和批量识别验证。

后续维护规则

  4. 每条结论区分已验证事实、基于证据的推断和待验证假设。
