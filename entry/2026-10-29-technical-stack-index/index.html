重构目标

第一版归档主要按照讨论场景分组，能够覆盖内容，但不利于形成稳定的学习体系。例如 Transformer、VLA 开源项目、DAgger 与人形控制被放在同一个“具身智能”分类中，SLAM 定位问题与导航控制问题也存在交叉。

新的知识树按技术栈组织。每个专题都尽量回答六类问题：基础概念是什么、系统结构怎样、算法如何工作、源码或现场证据是什么、工程上如何判断、还有哪些问题待验证。

覆盖范围

本次重构已分页读取 47 个历史会话，共获得 792 个可用对话回合和 786 条用户提问；另有 2 个 ChatGPT 来源只返回摘要预览。现有任务列表没有报告不可访问的数据源。

分类单位是对话回合，不是 Chat 窗口。同一 Chat 中关于模型、训练、部署或安全控制的不同回合会分别进入对应专题；同一回合如果同时涉及定位、导航与工程部署，也允许挂接多个专题。

公开页面只保留长期可复用的知识。设备信息、访问凭据、内部链接、本地路径、私人仓库配置、完整日志和原始聊天均不公开。

六条一级主线

1. 知识库系统

讨论多设备、多窗口 Chat 的首次全量导入、每日增量归档、私有 Markdown 源仓库、公开脱敏 Pages 和自动发布验证。

适合回答的问题是：知识如何从一次性对话变成可检索、可更新、可追踪且不会泄露隐私的长期资料。

2. SLAM 技术

覆盖激光与点云处理、Fast-LIO、关键帧地图、增量建图、动态残影、全局重定位、反光地标、视觉标志姿态、坐标变换和远程诊断。

适合回答的问题是：机器人如何建立地图、估计自身状态、发现定位失效，并用不同传感器互相校验。

专题目录：SLAM 技术。

3. 导航算法分析

覆盖全局规划、指定路线、MPPI、RPP、Rotation Shim、全向运动、代价地图、碰撞检查、障碍停车等待、视觉精导航、横向微移、任务生命周期和配置分层。

适合回答的问题是：有了地图与位姿后，机器人如何规划路径、生成速度、保证安全，并在故障后恢复任务。

专题目录：导航算法。

4. 模型相关基础知识

覆盖 Transformer 的查询、序列位置、占位向量、并行输出、注意力掩码，以及人形机器人的 MPC、WBC、浮动基座动力学、接触约束和控制层级。

适合回答的问题是：模型为什么使用动作查询输出轨迹，以及预测层计划如何变成物理机器人可执行的全身动作。

专题目录：模型相关基础知识。

5. VLN 开源项目学习

覆盖 OmTrackVLA、InternVLA-N1、NavDP、DualVLN、双视觉编码器、粗细粒度时序视觉表示、异步双系统、推理资源评估和 DAgger 数据闭环。

适合回答的问题是：具体开源模型如何把图像、语言和历史状态转换为导航轨迹，能否在目标硬件运行，以及如何继续训练和安全部署。

专题目录：VLN 开源项目学习。

6. 工程实践问题解决

覆盖代码工作区关系、交叉编译、完整集成部署、CI 分支判断、磁盘空间、日志权限、文件传输、版本回滚、Linux 软件包锁、桌面环境和实体标签制作。

适合回答的问题是：如何把算法变成可重复构建、可安全部署、可诊断、可验证和可回滚的工程系统。

专题目录：工程实践问题解决。

技术栈之间的依赖关系

模型基础提供表示学习、时序融合和控制优化的通用概念。VLN 项目把这些概念实现为具体网络。SLAM 提供地图、位姿和环境几何。导航算法把感知与定位结果转成安全运动。工程实践保证整套系统可以稳定构建、部署和复现。知识库系统则负责把所有结论持续沉淀。

可以把关系理解为：模型负责理解和预测，SLAM 负责建立世界状态，导航负责做出并执行局部运动决策，工程体系负责让所有模块真正运行，知识库负责保存可复用经验。

历史会话覆盖映射

SLAM 技术来源

  • 高反光材料导致异常点云及其同步诊断数据。
  • 平面视觉标志航向漂移和姿态双解。
  • 定位失败、地图位姿、里程计与坐标变换接口。
  • 远程 RViz 与导航调试桥。
  • Fast-LIO 运行负载与进程树分析。
  • PC 端视觉标志检测与质量可视化。
  • 增量建图、关键帧累加和动态残影。
  • 反光地标辅助定位与几何配准。
  • 激光强度字段可视化。
  • 视觉停靠状态日志与重对齐行为。

导航算法来源

  • 指定路线编辑、下发和一次规划。
  • 全向底盘、Rotation Shim、MPPI 与 RPP。
  • 障碍停车等待、静态地图校验和运动扫掠。
  • 后半平面点云过滤及其安全边界。
  • 视觉精导航、六自由度观测和速度控制。
  • 横向微移服务、停车锚点与离站。
  • 仿真与实车配置、任务类型配置和速度链路。
  • 生命周期暂停、定位抖动和任务恢复竞态。
  • 真机启动、路线标注、系统接口和状态报告。

模型基础与 VLN 来源

  • Transformer 为什么需要输出查询位置，以及查询向量训练后的含义。
  • 人形机器人 MPC 与 WBC 的职责、频率和接口。
  • OmTrackVLA 网络结构、动作输出和本机推理可行性。
  • InternVLA-N1 双系统、NavDP、DualVLN 与 RGB、RGB-D 取舍。
  • DAgger 训练阶段、连续轨迹标注、专家接管和危险样本处理。

工程实践来源

  • 地图与构建产物传输、文件完整性校验。
  • 多项目依赖、接口包升级和完整集成部署。
  • CI 失败对应的分支与提交关系。
  • 部署空间峰值、旧备份和回滚策略。
  • 日志目录权限与最小只读授权。
  • 远程桌面、输入法和软件包管理锁。
  • 实体视觉标签尺寸、静区、安装结构和批量识别验证。

后续维护规则

  1. 每日复盘只记录当天新增知识、决策和问题，不承担完整教材功能。
  2. 技术专题吸收跨天、跨窗口的长期知识，并随新证据更新。
  3. 同一主题优先更新既有专题，避免创建大量重复短文。
  4. 每条结论区分已验证事实、基于证据的推断和待验证假设。
  5. 每周检查技术栈之间是否出现新的依赖、冲突或知识空白。
