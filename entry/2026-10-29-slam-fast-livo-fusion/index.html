FAST-LIVO 怎样用激光和图像共同修正 IMU 预测

从共同状态出发，推导 IMU 传播、点到平面残差、光度残差和迭代滤波，解释紧耦合究竟发生在哪里。

FAST-LIVOFAST-LIO2紧耦合误差状态滤波点到平面

理解 FAST-LIVO 时，一个关键问题是：IMU 已经给出预测位姿，雷达和相机究竟在修改什么？它们是各算一条轨迹再取平均，还是直接参与同一个状态的估计？

答案是后者。IMU 提供随时间演化的状态及其不确定度；当前激光与地图之间的几何误差、当前图像与地图参考图像之间的亮度误差，分别约束这个状态。本文沿着“状态是什么—预测怎样产生—观测怎样纠偏—何时会失效”的顺序展开。地图点和参考图像的具体来源，接着读视觉地图与历史图像块。

先区分 FAST-LIO、FAST-LIO2 与原版 FAST-LIVO

1.1 本文讨论哪个版本

这里的 FAST-LIVO 指 2022 年论文及其原版开源实现，不把后来 FAST-LIVO2 的改进混入解释。FAST-LIVO 的激光惯性部分承接 FAST-LIO2；讨论“原始点直接配准”时，不能把这个特征无区别地归到所有早期 FAST-LIO 版本上。原版项目

理解维度FAST-LIO2原版 FAST-LIVO
主要输入激光、IMU激光、IMU、图像
IMU 的作用传播状态，支持扫描去畸变同样传播状态，并为图像对齐提供初值
激光提供的观测当前点相对地图局部表面的几何偏差保留这类几何约束
新增视觉观测无相机光度更新当前图像相对历史地图图像块的亮度偏差
理解地图时的重点三维几何及其查询几何之外，还要理解视觉参考观测

1.2 “直接”与“紧耦合”分别回答什么

“直接”描述怎样构造观测：激光侧将采样点与地图表面对齐；视觉侧使用像素亮度差，而不是先获得一组 ORB 描述子匹配再求位姿。直接使用激光点仍可能有下采样、无效点过滤和局部平面拟合，不能理解为完全没有预处理。

“紧耦合”描述这些观测进入哪里。如果先让激光算法输出位姿 A、视觉算法输出位姿 B，再融合两个位姿输出，原始观测的信息已经在各自求解中被压缩。这里讨论的结构则让几何残差、光度残差直接约束共同状态。它们不必使用同一批空间点，也不必每次同时到达。

IMU 预测的是状态与不确定度

2.1 位姿只是共同状态的一部分

用下面的简化状态帮助理解。不同实现可能在外参等变量的处理上不同，本文把传感器外参视为已标定量。

x = (R_GI, p_GI, v_G, b_g, b_a, g_G)

R_GI：IMU 坐标系到世界坐标系的旋转
p_GI：IMU 在世界坐标系中的位置
v_G ：世界坐标系中的速度
b_g、b_a：陀螺仪、加速度计的零偏
g_G ：世界坐标系中的重力向量

旋转矩阵有九个元素，但小旋转误差只需三个自由度。上述状态使用三维旋转扰动时，对应一个 18 维局部误差状态。滤波器还保存协方差，表达各分量的不确定度以及彼此相关性。

这解释了一个常见困惑：激光测量并未直接测量陀螺仪偏置，为什么更新后偏置也可能变化？因为预测过程中，偏置误差会影响姿态与位置，协方差记录了这种关联。观测对位姿的纠正可以通过相关项传到偏置和速度；但这不等于任何场景都能把所有变量准确观测出来。

2.2 从角速度、加速度到预测位姿

以下是一个用于理解的小时间步近似，省略噪声项和更高阶积分细节。实际工程必须遵守自身坐标及重力符号约定。

ω = ω_m − b_g
a_G = R_GI (a_m − b_a) + g_G

R_next = R_GI Exp(ω Δt)
v_next = v_G + a_G Δt
p_next = p_GI + v_G Δt + 0.5 a_G Δt²

Σ⁻ = F Σ Fᵀ + G Q Gᵀ

其中，陀螺仪读数为 ω_m，加速度计读数为 a_m；Exp 把小旋转向量转换成旋转矩阵。加速度计测的是比力，因此变换到世界系后还需按约定加入重力。F 是误差状态传播矩阵，G 把过程噪声映射到状态，Q 是过程噪声协方差，Σ⁻ 是预测协方差。

只积分 IMU 时，微小偏置会持续累积，所以预测既提供初值，也带着不确定度。雷达和相机的任务，就是用外部观测限制这种累积。

2.3 一帧点云为什么还需要去畸变

一次扫描中的不同点往往不是同一时刻采集。如果机器人边移动边扫描，却把全部点都当成在扫描结束瞬间测得，一面平墙可能被拼成弯曲或错位的表面。IMU 传播形成的运动估计可把各点换算到共同参考时刻，再进入后续配准。

因此“IMU 只负责初始位置”过于狭窄：它还提供扫描期间的运动信息。时戳或外参错误造成的结构性畸变，也不能指望增加优化迭代次数消除。相关数据链检查见点云异常诊断。

激光怎样把预测位姿变成可检验的几何量

3.1 当前点经过位姿变换后，应落到地图表面上

约定 T_AB 表示把 B 系坐标变到 A 系，点参与变换时使用齐次坐标。对已经去畸变的当前激光点 p_L：

p_G(x) = T_GI(x) T_IL p_L
r_L(x) = nᵀ [p_G(x) − q]

T_IL 是激光到 IMU 的外参，T_GI(x) 来自待估计状态。在地图中查询当前点附近的多个点，用这些邻点拟合局部平面；q 是平面上的一点，n 是单位法向量。r_L 就是当前点到该平面的有符号垂直距离，单位是米。

这里的“对应”是对应局部表面，不要求当前光束与某个历史光束命中完全相同的三维位置。平面拟合不可靠、邻域跨越两个物体或残差过大的点，应当经过有效性检查，不能全部当成等质量约束。

3.2 一个墙面例子：为什么不是最近点距离

以下数值仅用于演示。设地图中的墙为 X = 5 m，取 n = (1, 0, 0)，q = (5, 0, 0)。用预测位姿变换后的当前点为 (5.08, 2, 1)，则：

r_L = (1, 0, 0) · (0.08, 2, 1) = 0.08 m

它说明点沿墙法向偏了 8 cm。点与 q 在 Y、Z 方向的距离不应被当成墙面配准误差，因为 q 只是平面上的任一点。即使两个采样点相隔很远，只要都在同一无限平面上，这个理想平面残差仍然为零。

单个点的 8 cm 偏差不能唯一决定机器人该平移还是转动。系统需要很多点的空间分布共同区分运动自由度；同一面无限平墙对沿墙平移、绕墙法向旋转的约束很弱，这正是几何退化的一种来源。

相机怎样提供与几何不同的纠偏信息

4.1 位姿改变会改变地图点在图像中的位置

设历史地图点为 P_G，相机到 IMU 的外参为 T_IC。把点放进当前相机坐标系，再投影：

P_C(x) = T_IC⁻¹ T_GI(x)⁻¹ P_G
u(x) = π(P_C(x))

针孔示例：u_x = f_x X_C / Z_C + c_x
          u_y = f_y Y_C / Z_C + c_y

π 应使用真实标定对应的相机模型；上式只是无畸变针孔示例。若位姿有误，P_G 可能投到纹理旁边，当前位置采出的图像块就与历史参考不一致。光度残差衡量这种不一致，像素梯度和投影模型则提供“怎样改变位姿会减少残差”的局部信息。

4.2 光度残差不等于两个位姿相减

把经过几何变形、重采样的参考块记作 Q_ref_warped，对块内偏移 δ 的像素，可写出示意残差：

r_C,δ(x) = I_current(u(x) + δ) − Q_ref_warped(δ)

I_current 是当前图像亮度。一个块有多个像素，多个地图点又产生多个块，最终形成一组残差。参考块为何不是固定的前一帧、变形怎样处理，以及历史位姿具体起什么作用，在配套文章第 3、4 节展开。

一个有纹理的墙面可能在激光几何上接近平面，却在图像上含有文字、接缝或图案。沿墙移动时，点到平面距离变化很小，但纹理投影发生变化，因此相机有机会补充几何较弱的方向。若墙面纯白、严重模糊或曝光失真，这种补充信息也可能很弱。

两种残差怎样进入同一个迭代更新

5.1 状态转移模型与观测模型承担不同职责

“雷达和相机都基于 IMU 状态方程”需要拆成两层：它们共享同一状态和预测先验，但各有自己的观测模型。IMU 模型回答状态怎样随时间变化；激光模型回答给定状态后点应位于哪个表面；图像模型回答给定状态后地图纹理应出现在什么像素位置。

为理解权重和更新方向，考虑在预测状态附近的一次局部线性化。令 δx 为状态扰动，r 为当前有效观测的残差向量，H 为它对扰动的雅可比，R 为观测噪声协方差。一个简化的加权目标是：

J(δx) = δxᵀ (Σ⁻)⁻¹ δx
       + (r + H δx)ᵀ R⁻¹ (r + H δx)

[(Σ⁻)⁻¹ + Hᵀ R⁻¹ H] δx = −Hᵀ R⁻¹ r

第一项限制修正不要无依据地远离预测；第二项推动观测残差减小。协方差的逆表达信息权重：激光的米、图像的灰度不能不加区分地直接相加。实际实现还涉及流形扰动、异常观测处理以及迭代时先验误差的重新表达，上式用于理解一次局部求解，不是完整算法的替代代码。

5.2 为什么需要迭代，又为什么不能重复计数

位姿变了，点云与地图的几何关系、地图点的图像投影都会变化，观测函数因此具有非线性。一次线性化只在附近有效，迭代会在更新后的状态附近重新计算残差和雅可比，逐步改善对齐。

同一帧被迭代多次，并不等于获得了多次独立测量。正确的迭代滤波必须保留本次更新对应的预测先验；若把每次迭代都当作新独立观测反复压缩协方差，就会产生过度自信。状态修正也不是把旋转矩阵各元素直接相加，而应通过相应旋转扰动更新。

5.3 紧耦合不要求每个更新时刻同时有激光和图像

共同状态可以先由 IMU 传播到某次图像时刻，再接受图像观测；到某次激光观测时刻又接受几何更新。原论文的状态传播说明允许按激光或图像事件进行更新，因此“同一状态融合”不应被画成每一步必定同时堆叠两类残差的硬要求。原论文状态估计部分

但是，不同频率或异步到达不等于传感器时钟可以错开。原版运行说明明确强调同步数据，并指出未估计相机与 IMU 的时间偏移。采集时间相差几十毫秒的观测，在快速运动中可能描述不同姿态；消息晚到和消息时戳不准确，是两类不同问题。官方运行与同步说明

怎样判断融合真的有帮助

6.1 先检查信息是否存在，再检查权重

现象应检查的证据能支持的判断
几何简单的长墙附近漂移平面法向分布、弱约束方向、有效视觉纹理是否存在可由视觉补充的方向
增加相机后反而抖动时间对应、外参、重投影位置、曝光和模糊视觉是否在提供系统性错误约束
静止正常、快速转弯失效单点时戳、去畸变结果、图像曝光期间运动问题是否与运动和时序有关
大量像素但更新很弱梯度方向、有效地图点分布、剔除比例观测数量是否掩盖信息退化

这些是可复用的诊断路径，并非本次已经完成的实机测试。不能仅凭“有三种传感器”推断一定优于两种传感器，也不能只用残差变小证明位姿更接近真值：错误对应或错误噪声权重也可能产生看似漂亮的优化结果。

6.2 里程计、地图对齐与全局恢复仍需分开

本文解释的是在合理初值附近进行连续估计。局部对齐依赖地图与预测的相容性，不自动提供被搬走后的全局定位，也不证明历史地图没有漂移。全局候选生成与独立验证请接着读全局重定位与地标校验。

本次补充的依据是讨论中的完整追问链，以及原版论文和公开实现的交叉核对；没有测量某台设备的精度、耗时或故障恢复能力。部署结论仍需在明确版本、标定和数据集条件下验证。
